## Usage:
```
Arguments:
  <INPUT_PATH>  

Options:
      --compress                         
      --extract                          
      --output-path <OUTPUT_PATH>        
      --compress-level <COMPRESS_LEVEL>  [default: 5]
  -h, --help                             Print help

Example:
      ./rzip --compress test.txt --compress-level 10 --output-path test.txt.zst
      ./rzip --extract test.txt.zst
```
